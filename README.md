# Integrated Data Visualization for Healthcare and Tourism Licenses

## Overview
This project provides a Python-based solution for integrating and visualizing licensing data from the healthcare and tourism sectors in Abu Dhabi. By leveraging GIS mapping and data analysis tools, users can gain insights into active licenses, analyze trends, and identify geographic distributions.

## Prerequisites
- Python 3.8 or higher
- Pandas
- GeoPandas
- Matplotlib

## Installation
bash
pip install pandas geopandas matplotlib


## Data Sources
- **Healthcare Facility Licensing Dataset**: Available in CSV format.
- **Tourism Business Licenses Dataset**: Available in XLSX format.

## Running the Code
1. Place the datasets in the same directory as the script.
2. Modify the file paths in the script if necessary.
3. Run the script:
   bash
   python script_name.py
   

## Output
The script will generate a map showing the geographic distribution of active healthcare and tourism facilities in Abu Dhabi.

## Customization
- **Filtering Data**: Adjust the filter conditions to visualize specific subsets of data.
- **Adding Layers**: Include additional datasets or layers for more comprehensive analysis.
